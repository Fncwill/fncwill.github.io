# Free Sample Finder (Canada)
1. Create a GitHub repo and upload everything in this folder (keep `.github/workflows/`).
2. Settings > Pages > Deploy from branch `main` / root.
3. Actions tab > "Update samples" > Run workflow (it then runs every 6 hours).
4. Open your Pages URL, enter your details, drag the bookmark to your bookmarks bar.
5. Edit `FEEDS` in `scrape.py` to add or fix sources.
